# Inventory & Supplier Performance Analysis (SQL)

A small end-to-end SQL project that answers common supply chain and retail analytics questions: what sells, where the margin is, which suppliers are unreliable, and which products risk stocking out.

**Tools:** SQL (SQLite dialect), Python (data generation and database build, standard library only)
**Author:** Sudarshan Mane · [LinkedIn](https://linkedin.com/in/sudarshan-mane)

> **Data note:** All data is synthetic and generated by `scripts/generate_data.py` with a fixed random seed, so results are reproducible. No real company data is used.

---

## Business questions

The project is a set of 11 queries in `sql/02_analysis_queries.sql`, each answering a question a category manager or inventory planner would ask:

| # | Question | SQL techniques |
|---|----------|----------------|
| Q1 | Is the data clean? (row counts, date range, nulls) | aggregates, `CASE` |
| Q2 | Which categories earn the most revenue and margin? | `JOIN`, `GROUP BY` |
| Q3 | How does revenue trend month over month? | CTE, `LAG()` |
| Q4 | What are the top 3 products in each category? | `RANK() OVER (PARTITION BY ...)` |
| Q5 | How much does each store contribute to revenue? | window aggregate `SUM() OVER ()` |
| Q6 | Which products drive most revenue (ABC analysis)? | running total window, `CASE` |
| Q7 | How reliable is each supplier (on-time %, fill rate)? | `julianday()` date math, `RANK()` |
| Q8 | What is the value of short shipments by supplier? | conditional aggregation |
| Q9 | Which products risk stock-outs given lead time and demand? | multiple CTEs, derived metrics |
| Q10 | Which month is each category's seasonal peak? | `AVG() OVER (PARTITION BY ...)` |
| Q11 | How much higher are weekend sales than weekday sales? | `strftime()`, CTE |

## Data model

Five tables, about 31,000 sales rows and 327 purchase orders for one year (2025):

```
suppliers (supplier_id, supplier_name, country, standard_lead_time_days)
products  (product_id, product_name, category, supplier_id, unit_cost, unit_price, reorder_point)
stores    (store_id, store_name, city)
sales     (sale_id, sale_date, store_id, product_id, quantity, unit_price)
purchase_orders (po_id, order_date, product_id, supplier_id, qty_ordered,
                 promised_date, received_date, qty_received, unit_cost)
```

## How to run

Requires Python 3.8+ (no extra packages).

```bash
python scripts/generate_data.py   # optional: CSVs are already included
python scripts/build_db.py        # creates inventory.db
```

Then open `inventory.db` in [DB Browser for SQLite](https://sqlitebrowser.org/) or DBeaver and run the queries from `sql/02_analysis_queries.sql`, or from a terminal with the SQLite CLI:

```bash
sqlite3 -header -column inventory.db < sql/02_analysis_queries.sql
```

## Key findings

- **Beverages lead on revenue and margin.** Beverages bring in the most revenue (about 668K of 2.36M total) and the best margin (34.8%). Baking has the lowest margin at 29.4%.
- **Seasonality is clear.** Baking peaks in December (index 1.47 vs its own monthly average), beverages in August (1.31). Total revenue is highest in November and December, with a dip in September (-12.6% vs August).
- **One store carries a third of sales.** Downtown accounts for 34.3% of revenue; Charlottenburg for 16.9%. Weekend days run about 20% higher in revenue than weekdays in every store.
- **Revenue is spread broadly across products.** 15 of 25 products make up the "A" class (80% of revenue), a flatter curve than the classic Pareto pattern, so prioritising by ABC class alone would not narrow the focus much.
- **Two suppliers are clearly unreliable.** Alpine Snacks GmbH (57.0% on time) and EuroBake Supply (56.8%) are well below Maple Valley Foods and Sunrise Beverages (both 100%). Alpine also has the highest short-shipment value (4.6K across 14 short POs).
- **10 of 25 products are at stock-out risk.** Average demand during the supplier's actual lead time exceeds the reorder point. The five worst gaps are all supplied by EuroBake, Pacific Pantry or Alpine, so late deliveries and low reorder points compound each other.
